# PrismGEO brand kit

**PrismGEO** (one word, camel caps): *Track how AI assistants name your brand.*

The mark is a prism wedge (the question) refracting into three rays of decreasing length (the engines' answers, ranked).

| File | Use |
|---|---|
| `logo-mark.svg` | The mark. Wedge in Prism 600, rays in `currentColor`. |
| `logo-mark-mono.svg` | One-colour mark (all `currentColor`). |
| `logo-lockup.svg` | Mark and wordmark, text outlined. `currentColor`. |
| `favicon.svg`, `icon-512.png` | App icon: white mark on a Prism tile. Use below 20 px. |
| `og-image.png` | Link preview / GitHub social preview (1200×630). |
| `readme-banner.svg`, `readme-banner.png` | README header. |
| `brand-sheet.png` | Everything on one page: sizes, light and dark, palette. |

## Colour

| Role | Hex |
|---|---|
| Prism 600 (primary, "you") | `#5A37EE` |
| Prism 700 (hover, text on tints) | `#4A29D2` |
| Prism 400 (wedge on dark) | `#8B74FC` |
| Prism 50 / 100 / 200 (tints) | `#F3F1FF` / `#E8E4FF` / `#D2CAFF` |
| Ink | `#18181B` |
| Muted text (never lighter) | `#71717A` |
| Paper | `#FAFAFA` |

In charts and tables: **you** are Prism, **competitors** are neutral grey, **third-party** sites are an outline. Green, amber and red mean status only (working, partly blocked, blocked), never a company.

## Rules

- Keep clear space of at least the wedge's width around the mark.
- Minimum size: 20 px for the bare mark, 16 px for the tile, 96 px wide for the lockup.
- On dark backgrounds the rays follow the text colour; switch the wedge to Prism 400.
- Don't add a rainbow to the rays, recolour single rays, rotate or mirror the mark, add shadows or gradients, or set the wordmark in another font.

Wordmark outlines are from Inter Display SemiBold (SIL Open Font License 1.1).
