# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within PrismGEO, please send an email to the maintainer at **iliassami57@gmail.com** or through [iliassami.com](https://iliassami.com). All security vulnerabilities will be promptly addressed.

PrismGEO is a local-first software suite. It does not collect user analytics, telemetry, or remote crash reports. All keys, credentials, and scraped datasets are stored strictly on your local machine.
